-----------WINDOWS-----------

----SYNTAX----
- .hg is the file extension for Halogen source files.
- write() prints text.
- ask() requests input.
- var() declares a number variable; set assigns its value.
- str() declares a string; bool() declares a Boolean.
- get retrieves and prints a variable's value.
- #/ ... \# marks comments.
- rpt, functions, and conditional blocks all close with end.
- elif is supported between if and else.
Still to define: arithmetic rules, function parameters and return values, and the assignment syntax for storing the result of ask(). Those are open design decisions for the next version of Halogen.
